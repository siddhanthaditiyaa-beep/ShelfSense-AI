🤖 40 AI Agents Guide

🔔
Monitoring Agent
Runs every 30 seconds. Alerts when stock = 0 (email sent) or stock ≤ minimum level (in-app warning).
📊
Forecasting Agent
Runs every 15 minutes. Uses exponential smoothing + weekend 1.3x multiplier. Auto-restocks when days until empty ≤ 3.
🛡️
Anomaly Detection Agent
Runs every 45 seconds. Uses Z-score analysis. Outside shop hours = theft alert email sent immediately.
💰
Dynamic Pricing Agent
Runs every hour. High demand + low stock = +10% price. Low demand + excess stock = -10% price.
🏆
Competitor Analysis Agent
Runs daily at 9 AM. Compares your prices with market averages. Alerts if 15%+ above or below market.
🔄
Supplier Agent
Runs every 2 hours. Creates purchase orders when stock ≤ minimum. Stock updates when you click Mark Received.
👥
Customer Behavior Agent
Runs daily at 1 AM. Uses co-occurrence analysis to find products bought together. Suggests bundle deals.
🌦️
Weather Agent
Runs daily at 8 AM. Fetches real weather from Open-Meteo API. Recommends cold drinks in heat, snacks in rain.
📅
Expiry Agent
Runs daily at 7 AM. Auto-applies 30% discount on items expiring within 7 days. Urgent email for expired items.
🗺️
Route Optimization Agent
Runs daily at 6 AM. When stock = 0, finds nearest franchise with 5+ units using Haversine distance formula.
😊
Sentiment Analysis Agent
Runs daily at 2 AM. Analyzes average ratings to compute sentiment scores. Negative sentiment triggers quality review alerts.
📈
Demand Surge Agent
Runs every 2 minutes. Detects when product views exceed 50 or cart additions exceed 20 with low stock. Sends immediate reorder alerts.
🚨
Fraud Detection Agent
Runs every minute. Flags accounts placing 5+ orders in 10 minutes, quantities over 50 units, or amounts over ₹50,000 as suspicious.
🏷️
Auto Discount Agent
Runs daily at 10 AM. Products selling less than 2 units/week with 15+ in stock get automatic 15% discount. Removed when sales recover.
🔔
Smart Notification Agent
Runs every 30 minutes. Sends personalized emails to customers when their wishlisted out-of-stock items are back in stock.
⏰
Peak Hours Agent
Runs every hour. Analyzes order history by hour of day to find peak sales time. Alerts store owner 1 hour before rush so shelves are fully stocked.
📉
Price Elasticity Agent
Runs every 6 hours. Compares first half vs second half of sales history to detect if price changes are helping or hurting demand. Suggests price adjustments.
📦
Reorder Point Agent
Runs every 30 minutes. Calculates optimal reorder point using formula: (avg daily sales × 3 day lead time) + safety stock. Auto-creates purchase order when threshold hit.
