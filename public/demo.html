🪖
Layer 3: Helmet.js Headers
OWASP A05
15 HTTP security headers — HSTS, X-Frame-Options, CSP, X-Content-Type-Options.

Layer 4: Rate Limiting
OWASP A04
20 requests/15min limit — excess requests blocked with HTTP 429 Too Many Requests.
💉
Layer 5: NoSQL Injection Guard
OWASP A03
express-mongo-sanitize strips $ operators — injection attacks fail silently.
🛡️
Layer 6: XSS Protection
OWASP A03
xss-clean strips all script tags from input — cross-site scripting attacks blocked.
🍯
Layer 7: Honeypot Detection
OWASP A04
Hidden field in all forms — humans never see it, bots fill it — auto-blocked.
🧬
Layer 8: Biometric Anomaly
NIST, ISO A.7
Typing speed deviation >80% from baseline flags login as anomalous even with correct password.
📋
Layer 9: Audit Logging
OWASP A09
Every action logged with IP, timestamp, user agent — nothing escapes the audit trail.
🔐
Layer 10: Account Lockout
OWASP A07
5 wrong passwords = 30-minute lockout. Prevents brute force attacks completely.
🛂
Layer 11: CSRF Protection
OWASP A08
Token-based CSRF on all POST/PUT/DELETE routes — cross-site request forgery blocked.
💳
Layer 12: Fraud Detection
PCI-DSS

🌐
Layer 13: HTTPS + CORS
OWASP A05
